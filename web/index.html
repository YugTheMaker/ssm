Variable shortcuts

Directly edit any key or variable in your save file (`variables.stuff`). Perfect for custom flags, story states, or any hidden values.

Common Variable Presets (Click to fill):
sM (Fire Funding) Og (Firefighter Rank: 0-7) sR (Doctor Rank: 0-3) BZ (Medical Diploma) 3N (Fire Promotion Pending) wa (Arcade Game Upgrade) po (Fire Water Cannon) 8T (Fire Engine HP) R9 (Fire Engine Tank) ni (Fire Engine Hoses) wH (Fire Jacket Protection) YK (Fire Oxygen Tank) Oz (Salary Bonus %) nt (Bird Sanctuary Funding) Rk (Bird Sanctuary Level: 1-5) flag:sz (Is Bird Photographer) flag:NI7q (Sanctuary Boardwalk) flag:dri1 (Sanctuary Tower)
Prefix with flag: to force writing inside the save's flags table, or use any standard key.

Save fields

Browse the selected slot’s save files and edit values by key. Use the controls above for changes that affect multiple fields.

Use quotes for text. Edit nested objects and arrays directly in the JSON.

Quit Sneaky Sasquatch with ⌘Q before editing. Backups are saved in console-backups/. Undo restores the most recent unchanged file in the selected slot.
